# 06. Rekap Fitur (Feature Recap)

Daftar fitur MVP yang diperbarui berdasarkan proposal PFmuda 2026 dan catatan teknis:

## 1. Fitur Utama Pengguna (Teman Tuli)
*   [x] **Registrasi & Login (Supabase Auth)**
*   [x] **Pemesanan JBI Berbasis Peta (PostGIS)**
*   [x] **Live Tracking & Estimasi Kedatangan**
*   [ ] **Sistem Pembayaran / Billing:** Kalkulasi tarif *flat-rate* per jam.
*   [ ] **Persetujuan Term of Service (ToS):** Aturan ketat penggunaan aplikasi.

## 2. Fitur Utama Mitra (JBI)
*   [x] **Toggle Ketersediaan Offline (Geolokasi)**
*   [ ] **Unggah Sertifikat JBI:** Bukti kualifikasi profesional/relawan saat pendaftaran.
*   [x] **Manajemen Pesanan (Terima/Selesaikan)**
*   [ ] **Wallet / Saldo JBI:** Halaman khusus untuk melihat penghasilan (90% dari tagihan).
*   [ ] **Penarikan Uang (Withdrawal):** Sistem mencairkan dana saldo ke rekening bank JBI.

## 3. Fitur Keamanan Bisnis & Keberlanjutan
*   [ ] **Integrasi Payment Gateway:** (Midtrans/Xendit) untuk memproses pembayaran dan pencairan.
*   [ ] **Sistem Deteksi Back-Channeling:** Mencegah terjadinya transaksi "di belakang" aplikasi.
*   [ ] **Sistem Komisi Platform (10%):** Otomatisasi pemotongan dana untuk operasional aplikasi (wirausaha sosial).
