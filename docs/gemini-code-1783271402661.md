# Requirements-Driven Prompting (RDP) - Setara App (Offline-First)

**Cara Penggunaan:**
Berikan *prompt* ini secara berurutan kepada Kiro di VSCode. Pastikan Kiro menyelesaikan dan kamu telah memvalidasi (serta *commit*) satu modul sebelum melanjutkan ke *prompt* berikutnya.

---

## 💡 Prompt 0: Pengondisian Sistem (System Context)
*Tujuan: Memberikan konteks awal kepada asisten AI tentang arsitektur spasial proyek.*

**Input Prompt:**
> "Kiro, kamu adalah *Senior Full-Stack Engineer* yang ahli dalam Next.js (App Router), Tailwind CSS, dan Supabase (termasuk ekstensi PostGIS). Kita akan membangun MVP aplikasi bernama 'Setara', sebuah platform *on-demand* O2O (*Online-to-Offline*) yang menghubungkan Teman Tuli dengan Juru Bahasa Isyarat (JBI) terdekat untuk pendampingan langsung.
> 
> Tumpukan teknologi yang digunakan: Next.js, Supabase (Auth, Database, Realtime, PostGIS), dan Mapbox/Google Maps API.
> 
> Tugasmu adalah menulis kode yang bersih, modular, dan mematuhi prinsip aksesibilitas (a11y). Jawab 'SIAP' jika kamu mengerti konteks ini, dan kita akan mulai langkah pertama."

---

## 🗺️ Prompt 1: Setup Database Spasial & Skema Dasar
*Tujuan: Menyiapkan Supabase dengan kemampuan pemetaan.*

**Input Prompt:**
> "Buatkan skema SQL untuk PostgreSQL di Supabase yang mencakup konfigurasi spasial berikut:
> 1. Aktifkan ekstensi PostGIS.
> 2. Buat tabel `users`: `id` (UUID dari auth.users), `role` (enum: 'deaf_user', 'jbi'), `full_name` (text).
> 3. Buat tabel `jbi_profiles`: `user_id` (FK ke users.id), `offline_available` (boolean, default false), `current_location` (tipe geometry Point 4326), `specialty` (text).
> 4. Buat tabel `offline_bookings`: `id` (UUID), `user_id` (FK), `jbi_id` (FK), `meeting_point` (geometry Point 4326), `address_detail` (text), `status` (enum: 'searching', 'heading_to_location', 'arrived', 'in_progress', 'completed').
> 
> Berikan kode SQL-nya beserta instruksi singkat penerapan RLS (Row Level Security)."

---

## 🖥️ Prompt 2: Autentikasi & Routing Frontend
*Tujuan: Membangun pintu masuk aplikasi.*

**Input Prompt:**
> "Buatkan halaman autentikasi (Login/Register) menggunakan Next.js App Router dan Supabase Auth. 
> Persyaratan:
> 1. Gunakan Tailwind CSS untuk UI.
> 2. Form pendaftaran meminta nama lengkap, email, password, dan pilihan *role* (Pengguna atau JBI).
> 3. Setelah *login* berhasil, arahkan *role* 'deaf_user' ke `/dashboard/user` dan *role* 'jbi' ke `/dashboard/jbi`.
> Tuliskan komponen UI dan fungsi klien/server yang dibutuhkan."

---

## 📍 Prompt 3: Integrasi Peta & Pemesanan (Sisi Pengguna)
*Tujuan: Membuat antarmuka penentuan titik kumpul.*

**Input Prompt:**
> "Buatkan komponen UI di `/dashboard/user` untuk memesan JBI secara *offline*.
> 1. Gunakan *Geolocation API* browser untuk mendapatkan titik koordinat pengguna saat ini. Jadikan kota Surabaya (sekitar lat: -7.2504, lng: 112.7688) sebagai nilai *fallback* atau titik tengah *default* jika lokasi gagal didapatkan.
> 2. Buat antarmuka peta sederhana (gunakan *mockup* div atau integrasikan Mapbox GL JS) dengan sebuah *marker* titik pertemuan.
> 3. Tambahkan *text area* untuk memasukkan patokan alamat rinci.
> 4. Sediakan tombol 'Cari JBI' yang akan menyimpan data tersebut ke *state* lokal sebelum dikirim ke *backend*."

---

## 🔍 Prompt 4: Logika Matchmaking Spasial (Backend)
*Tujuan: Mencocokkan pengguna dengan JBI terdekat.*

**Input Prompt:**
> "Kita butuh logika pencarian JBI terdekat. Buatkan sebuah *Stored Procedure* (Fungsi SQL) di Supabase bernama `find_nearest_jbi`.
> 1. Fungsi ini menerima parameter: `lat` (float), `lng` (float), dan `radius_meters` (integer).
> 2. Fungsi ini harus mencari di tabel `jbi_profiles` di mana `offline_available` bernilai TRUE.
> 3. Hitung jarak antara koordinat input dan `current_location` JBI menggunakan fungsi `ST_DistanceSphere` dari PostGIS.
> 4. Kembalikan data JBI yang berada dalam radius tersebut, diurutkan dari yang paling dekat.
> Berikan *script* SQL untuk membuat fungsi ini."

---

## 🚕 Prompt 5: State Management & Realtime Tracker
*Tujuan: Melacak pergerakan JBI layaknya aplikasi ride-hailing.*

**Input Prompt:**
> "Buatkan komponen *Live Tracker* untuk `/dashboard/user` dan `/dashboard/jbi`.
> 1. Gunakan `Supabase Realtime Subscriptions` untuk mendengarkan perubahan pada tabel `offline_bookings` secara instan.
> 2. **Sisi Pengguna:** Tampilkan UI dinamis yang berubah mengikuti status ('Mencari JBI', 'JBI Menuju Lokasi', 'JBI Tiba', 'Sesi Berlangsung').
> 3. **Sisi JBI:** Buatkan tombol antarmuka yang memungkinkan JBI memperbarui baris pesanan tersebut (menekan tombol 'Terima Pesanan' yang mengubah status ke 'heading_to_location', lalu 'Saya Sudah Tiba', dan 'Selesaikan Sesi').
> Berikan contoh kode komponen React yang mengelola logika *subscription* dan pembaruan *state* ini."
