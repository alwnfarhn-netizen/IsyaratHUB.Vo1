# 07. Next Steps & Roadmap

Fokus pengembangan bergeser pada integrasi sistem *billing*, keuangan, serta kesiapan peluncuran (Soft Launch) sesuai dengan *timeline* 5 bulan dari PFmuda 2026.

## 1. Prioritas Jangka Pendek (Bulan 1-2)
*   **Implementasi Sistem Pembayaran (Payment Gateway):** Memulai integrasi dengan layanan *Payment Gateway* (seperti Midtrans atau Xendit) untuk memfasilitasi transaksi tagihan dari Teman Tuli ke JBI.
*   **Pembuatan Sistem Dompet (Wallet):** Membangun UI dan API (Supabase Functions) untuk perhitungan komisi 10% dan pencatatan mutasi saldo JBI.
*   **Modul Verifikasi JBI:** Membangun antarmuka unggah (*upload*) Sertifikat JBI dan *dashboard* admin untuk proses validasi kelayakan mitra.

## 2. Jangka Menengah (Bulan 3-4)
*   **Integrasi Term of Service (ToS) & Anti-Back-Channeling:** Memastikan persetujuan kontrak digital masuk ke sistem dan mengaktifkan algoritma pemantauan sesi pembatalan.
*   **Uji Coba Lapangan (Pilot SLB Karya Mulya):** Melakukan *soft launching* secara terbatas untuk memvalidasi alur pemesanan spasial dan alur penarikan uang (*withdrawal*) JBI.

## 3. Keberlanjutan Jangka Panjang (Bulan 5 dan Pasca PFmuda)
*   **Sosialisasi Komunitas & Institusi:** Mendorong langganan premium bulanan (*Subscription*) bagi rumah sakit atau perguruan tinggi di Surabaya.
*   **Penyusunan Laporan Proyek Sosial:** Membuat dokumentasi dampak sosial perdana sesuai dengan metrik keberhasilan PFmuda (≥50 sesi, ≥20 JBI).
*   **Replikasi Layanan:** Mempersiapkan arsitektur aplikasi (sebagai perangkat lunak *open-source*) agar siap diaplikasikan pada komunitas JBI di kota-kota lain.
